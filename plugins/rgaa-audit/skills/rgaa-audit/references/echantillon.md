# Échantillon de pages

Un audit RGAA porte sur un échantillon, pas sur le site entier. Un échantillon mal constitué
invalide le taux de conformité : c'est la première chose à contrôler, avant toute mesure.

## Pages obligatoires

Toutes celles qui existent sur le site :

1. page d'accueil ;
2. page de contact ;
3. mentions légales ;
4. **déclaration d'accessibilité** ;
5. plan du site ;
6. page d'aide / FAQ ;
7. page de résultats de recherche ;
8. page d'authentification (et création de compte) ;
9. page à processus (tunnel : formulaire multi-étapes, commande, candidature, paiement) —
   **chaque étape compte pour une page**.

Une page obligatoire absente du site n'est pas un manquement d'échantillon, mais il faut le dire :
l'absence de déclaration d'accessibilité est elle-même une non-conformité (critère 13 / obligation
légale distincte du RGAA technique).

## Pages représentatives

En plus, au moins 8 pages au total, choisies pour **maximiser la variété des gabarits et des
composants**, pas pour faire du nombre :

- un gabarit de chaque type (accueil, page de contenu, liste/archive, fiche/détail) ;
- toute page contenant un **tableau de données**, un **média** (vidéo, audio, carte, visionneuse),
  un **formulaire complexe**, un **cadre** (iframe), un **composant interactif** (onglets,
  accordéon, carrousel, modale, filtre dynamique) ;
- au moins une page profonde, pas seulement le premier niveau ;
- si le site est multilingue, au moins une page dans une autre langue ;
- si le rendu mobile diffère du rendu bureau au-delà de la mise en page, le signaler.

## Éléments transverses

Ce qui est identique partout — en-tête, menu principal, pied de page, bannière cookies, fil
d'Ariane — se traite dans la page « Éléments transverses » d'Ara, pas dupliqué page par page.
Les critères de navigation (12.1 à 12.7) et une partie des éléments obligatoires y vivent
naturellement.

**La bannière cookies fait partie du site.** Elle s'audite : nom accessible des boutons, focus
piégé, contraste, accès clavier.

## Avant de lancer l'audit

Comparer l'échantillon existant à cette liste et **dire explicitement à l'utilisateur ce qui
manque**, avec l'effet sur la validité du résultat. Ne pas ajouter de page en silence : proposer.
